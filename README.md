# Cannon Fodder Plaque

A printable plaque of the names of the soldiers in the game [Cannon Fodder](https://en.wikipedia.org/wiki/Cannon_Fodder).

The plaque is implemented in [Typst](https://typst.app/), a markup-based typesetting system. The source code is in `cannon-fodder-plaque.typ`.

I copied the list of soldier's names from <https://gamefaqs.gamespot.com/arch/961531-cannon-fodder/faqs/60138>.
